FM27 Attribute Port for FM24

Updates existing FM24 players with their FM27 attributes and data.

Required Base Mod: This database modifies existing players and does not add missing players to the game. You must run this alongside the SortitoutSI Football Manager Data Update (2026 Start Date). Download their update and follow their specific installation instructions first.
Critical Setup: When starting your save, you must select the official FM24 24.3.0 Database. Do not use other custom attribute-altering databases alongside this port, or you will encounter conflicting player data.
Download FM27 Port (.fmf)

Installation & Setup:

  1. Install the SortitoutSI data update using the link above.
  2. Click the green download button to grab the FM27_to_FM24_Port.fmf file.
  3. Move this .fmf file into your FM24 editor data directory:
    • Windows: Documents\Sports Interactive\Football Manager 2024\editor data
    • Mac: Documents/Sports Interactive/Football Manager 2024/editor data
  4. Launch Football Manager 2024 and select Start a New Game > Career.
  5. In the top right corner, ensure the database version is set to exactly 24.3.0.
  6. Check the box for both the SortitoutSI files and FM27_to_FM24_Port, then confirm and start your save.
